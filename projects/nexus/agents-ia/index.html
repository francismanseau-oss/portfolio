Agents IA

WSAI est le système multi-agents du projet phare Nexus. Il héberge sept agents spécialisés, chacun avec un rôle net et un périmètre défini — orchestrés depuis Nexus Mobile et exécutés sur mon environnement de travail.

Les sept agents

  • Virtuose
  • Mia
  • Kenji
  • Guardian
  • Oscar
  • Elena
  • Postman

Virtuose

Code / administration

Agent de code relié à Cursor. C’est lui qui modifie les fichiers, les scripts, les builds et les configurations du workspace. Depuis Nexus Mobile, les demandes @admin lui sont transmises pour exécuter le développement sur mon PC.

Mia

Orchestration / coordination

Coordinatrice de l’équipe WSAI. Elle clarifie les demandes, priorise, synthétise l’état de la plateforme et oriente vers le bon agent — sans exécuter à la place des autres.

Kenji

Rédaction / LLM / support

Rédacteur et assistant technique. Il répond aux questions, rédige des explications concrètes et s’appuie sur la base de connaissances — notamment pour le soutien HK Crib GO lorsque c’est pertinent.

Guardian

Sécurité / sauvegardes / garde-fous

Agent de protection. Il observe l’état Git, les sauvegardes et les garde-fous, signale les situations à risque et propose des actions prudentes — sans exécuter backup ni commit depuis le chat.

Oscar

Opérations / plateforme

Agent ops et santé runtime. Seul agent avec les capteurs machine : RAM, CPU, disque, GPU, température, file de travail, LLM et alertes de la plateforme WSAI.

Elena

Administration & catalogues

Agent admin. Elle gère les catalogues produits et services, les propositions administratives et les registres internes — avec des chiffres réels issus du ledger, jamais inventés.

Postman

Courriels / MailPerso

Agent courriel de MailPerso. Il analyse et classe les messages reçus, résume la boîte de réception par catégorie et signale ce qui mérite attention — sans action destructive sur les courriels.
